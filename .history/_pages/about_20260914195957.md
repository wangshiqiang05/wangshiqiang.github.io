### Open‑Vocabulary Object Recognition for Corneal Reflection Images
*First‑Author, under double‑blind review*

I propose an optics‑guided prompt synthesis pipeline to construct paired synthetic training data, and design a Degradation‑Aware Reflection Enhancement Network (REDA‑Net) combined with scene‑guided privileged‑context training. The full pipeline covers iris localization, reflection enhancement, and zero‑shot open‑vocabulary recognition with vision‑language models.

- Quantitative result: semantic matching accuracy improved from 51.50% to 66.17% on synthetic benchmarks.
- Edge performance: end‑to‑end inference latency **319.89 ms** on Raspberry Pi 5.

## Projects
### Bidirectional Multimodal Sign‑Language Translation System on RK3588
> Core Member | 2nd Prize, National Embedded Chip Competition

Designed and implemented the full code framework for end‑to‑end bidirectional sign‑language translation targeting hearing‑impaired users on RK3588.
- Recognition branch: MediaPipe hand keypoint extraction, CNN for static gestures, CNN+Transformer for continuous sign‑language temporal modeling.
- Generation branch: text tokenization and sign‑material assembling for sign‑language animation.
- Deployed on RK3588 ELF2 with NPU acceleration, supporting real‑time bidirectional translation for 30+ static gestures and continuous phrases.

### Blind‑Assisting System Fusing Smart Cane & Smart Glasses via Crowd‑Perception
> Team Leader | 3rd Prize, National AI Creativity Contest

Proposed a distributed collaborative navigation solution for visually‑impaired pedestrians: smart cane for ground‑level hazards and smart glasses for front‑view risks.
- YOLO‑series object detection + traditional computer vision for obstacle / stair detection; optical‑flow assisted face recognition.
- Integrated Beidou & Baidu map navigation with yaw replanning; multi‑level voice‑vibration alert mechanism; family‑guardian mini‑program status synchronization.
- Deployed on Raspberry Pi 5, detecting over 10 obstacle categories with end‑to‑end latency under 200 ms.
